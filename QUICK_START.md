## 🎮 Controls Cheat Sheet

### Keyboard Controls
- **Arrow Keys:** Snake, Tetris
- **SPACE:** Snake (start), Pong (pause), Tank Flight (jump), Tetris (hard drop)
- **A/D Keys:** Pong (move paddle)
- **Mouse:** All games support mouse clicks!

### Universal
- **Click buttons** for all menu-based games
- **ESC** to pause (where applicable)

## 💡 Pro Tips

| Game | Quick Tip |
|------|-----------|
| Hangman | Guess vowels first (A, E, I, O) |
| Tic-Tac-Toe | Take the center square |
| Snake | Plan 3-4 moves ahead |
| Pong | Anticipate ball angle |
| Blackjack | Stand on 17+ |
| Sudoku | Look for obvious numbers first |
| Memory | Remember positions, not just emojis |
| Tetris | Keep stack flat, use I-piece for clears |
| Ludo | Rush to exit home base |
| Tank Flight | Tap lightly, don't hold |
